Rule 110 Computer

An experimental computer whose every logic gate is a single Rule 110 cell update. A task is compiled to a circuit, the circuit is scheduled into layers, and each layer is one row of cells evolved one Rule 110 generation. The host bus only copies bits between rows (wires) and supplies constant rails — it performs no logic. The canvas is the resulting spacetime diagram.

Controls

  • Hover: Inspect cell / gate / wiring
  • Scroll: Zoom (out to full layer width)
  • Right / middle drag: Pan horizontally / vertically
  • Space: Play / Pause
  • N / C: Step layer / Step cycle
  • I: Invert colors

The Rule

Rule 110 · (left, centre, right) → new centre
Gate triples · rail sets the gate, a b are inputs
Canvas colours · bright = 1, dark = 0
